# NutriQuest — Corrida do Conhecimento

App de estudo da turma: 569 flashcards com repetição espaçada (FSRS), laboratório de cálculos em nutrição esportiva, simulado e corrida em quilômetros.

- Página: publicada pelo GitHub Pages a partir deste repositório.
- Dados: ficam na planilha "NutriQuest — Dados da turma" do Google Drive do professor, acessada pelo servidor do Google Apps Script.
